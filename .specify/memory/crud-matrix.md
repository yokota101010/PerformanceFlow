# システム全体鳥瞰図 (CRUD Matrix)

本書は、システムで扱う各ドメイン集約（[domain-model.md](file:///.specify/memory/domain-model.md)）と、アプリケーションが提供する主要機能（画面・ユースケース）との関係性を示したシステム全体の鳥瞰図（CRUD対応表）である。

本ドキュメントは、システム開発憲法（[constitution.md](file:///.specify/memory/constitution.md)）で定義されている **「単一トランザクション・単一集約の原則」** および **「Command系（変更系）画面の制約」** に基づき、ドメイン集約の境界と1対1で対応する機能（Command）構成として設計されています。

## CRUD マトリクス (CRUD Matrix)

各機能が各ドメイン集約に対して実行する操作（**C**: Create / **R**: Read / **U**: Update / **D**: Delete）の対応表です。

憲法に定める **「結果整合性の許容とプル型同期（オンデマンド再計算）」** およびドメインモデルの **外部キー（FK）依存関係** に従い、機能構成と操作権限を定義しています。

※ `四半期区分` は固定のコード定義（システム定数）として扱われるため、設定画面（Command）は提供されません。

### 表記記号
- **CRUD**: 集約全体の作成・参照・更新・削除権限（Command系の主担当集約）
- **R**: 参照権限（関連チェック・選択肢取得・オンデマンド集計参照など）

## 単一トランザクション・単一集約原則の遵守確認

1. **Command機能（F01〜F10）の更新対象集約は必ず1つ**:
   - 各 Command 機能は自らの担当集約（Aggregate Root）に対してのみ **CRUD** (書き込み) 操作を行い、他集約への書き込みは一切行いません。
   - 他集約の参照（**R**）は、外部キーのバリデーションやドロップダウン選択肢取得のための読取専用アクセスです。
2. **サマリ集約（F13〜F14）の結果整合性（オンデマンド算出）**:
   - 導出サマリ集約（`月別社員工数サマリ`, `月別要員工数サマリ`, `月別案件明細原価`, `四半期別案件明細業績`）は、Query画面表示時に一次データよりオンデマンドで算出・参照されます。
