## 2. ドメインエンティティおよび制約ルール (Domain Rules)

### 単一集約更新ルール (Command Rules)
- **F01〜F11 の各画面は対応する集約ルートのみ更新**:
  - `社員` の更新時に `社員単価` を同一操作で書き換えてはならない。
  - `案件` の更新は `案件` ルートと `案件明細` メンバーのみを一括永続化する。
  - `発注` の更新は `発注` ルートと `注文明細` メンバーのみを一括永続化する。

### 導出項目のオンデマンド算出ロジック (Query Projection Rules)
- `月別案件明細原価`:
  - `社員原価` = $\sum (\text{月別案件社員工数.工数人月} \times \text{月別社員単価.単価})$
  - `外注原価` = $\sum (\text{注文明細.発注金額})$（対象年月の発注）
  - `経費` = $\sum (\text{その他経費.金額})$
  - `粗利` = $\text{売上} - (\text{社員原価} + \text{外注原価} + \text{経費})$
