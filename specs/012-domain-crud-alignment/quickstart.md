# Quickstart & Validation Guide: Domain Model & CRUD Matrix Alignment

本ドキュメントは、機能改修後の動作・整合性検証を即座に実行するためのガイドです。

## 1. 事前準備と起動

```bash
# パッケージの依存関係確認
npm install

# 開発サーバー起動（ブラウザでの直接検証）
npm run dev

# ユニット/ドメインモデルテストの実行
npm run test
```

## 2. 検証シナリオ

### シナリオ 1: 単一集約更新の動作検証 (Command 隔離テスト)
1. ブラウザで「案件管理（F05）」または「社員単価設定（F08）」を開く。
2. 案件明細または単価履歴の追加・修正を行って保存する。
3. `LocalStorage` 内のストアデータ（DevTools の Application タブ）を確認し、`案件` または `社員単価` のキーのみが更新され、関連する `社員` や `発注先` のキーに変化がないことを確認する。

### シナリオ 2: プル型オンデマンド集計の検証 (Query プル同期テスト)
1. 「工数入力（F07）」画面で当月の工数を更新する。
2. 「社員別工数サマリ表示（F13）」画面へ遷移する。
3. 一括バッチや同期処理を挟むことなく、遷移時に動的に最新の工数・単価に基づいた工数サマリが即座に動的計算・表示されることを確認する。
